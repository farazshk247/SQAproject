# Running the Front End and Back End

## 1. Requirements

The following are required to run the project:

- Git
- Python 3
- C++17 compiler (g++ or clang++)
- Visual Studio Code (recommended)
- Windows: WSL 2 with Ubuntu
- Linux: Ubuntu or another compatible Linux distribution
- macOS: Apple Command Line Tools

Repository: https://github.com/farazshk247/SQAproject.git

## 2. Windows (WSL + Ubuntu)

### Step 1: Install WSL and Ubuntu

Open PowerShell:

```powershell
wsl --install -d Ubuntu
```

Follow the instructions to set up Ubuntu.

Launch Ubuntu:

```powershell
wsl -d Ubuntu
```

### Step 2: Install dependencies

Run inside Ubuntu:

```bash
sudo apt update
sudo apt install -y git g++ python3
```

### Step 3: Open the repository

Clone the repository:

```bash
git clone https://github.com/farazshk247/SQAproject.git
cd SQAproject
```


### Step 4: Compile

```bash
g++ -std=c++17 front_end/*.cpp -o frontend_phase4_linux
```

Verify compilation:

```bash
echo $?
ls -l frontend_phase4_linux
```

If the result is 0 it compiled successfully.

Continue to section 5.

## 5. Running the Front End and Back End

The following commands work on Windows WSL/Ubuntu, Linux, and macOS.

Run all commands from the root of SQAproject.

### Step 1: Run the Front End

The project already contains the required input files in test_cases/common/.

```bash
./frontend_phase4_linux \
test_cases/common/current_user_accounts.txt \
test_cases/common/available_games.txt \
test_cases/common/game_collection.txt \
/tmp/sqa_phase4_daily.txt
```

The Front End reads commands from standard input.

For example, enter the following commands one at a time:

```text
login
admin1
create
testuser
FS
logout
```

This logs in as an administrator, creates a full-standard user named testuser, and writes the Daily Transaction File.

### Step 2: Check the Daily Transaction File

```bash
cat /tmp/sqa_phase4_daily.txt
```

This displays the transactions generated by the Front End.

### Step 3: Run the Back End

```bash
python3 back_end/main.py \
test_cases/common/current_user_accounts.txt \
test_cases/common/available_games.txt \
test_cases/common/game_collection.txt \
/tmp/sqa_phase4_daily.txt \
/tmp/sqa_new_accounts.txt \
/tmp/sqa_new_games.txt \
/tmp/sqa_new_collection.txt
```

The Back End processes the transactions and generates updated accounts, games, and collection files.

### Step 4: Check the Back End Output

View the updated accounts:

```bash
cat /tmp/sqa_new_accounts.txt
```

If the user creation succeeded, the output will include:

```text
testuser        FS 000000.00
```

View the updated games:

```bash
cat /tmp/sqa_new_games.txt
```

View the updated collection:

```bash
cat /tmp/sqa_new_collection.txt
```

The original input files in test_cases/common/ remain unchanged. The generated files are saved in /tmp.

## 6. Running Again

To recompile the Front End:

**Linux / Windows WSL:**

```bash
g++ -std=c++17 front_end/*.cpp -o frontend_phase4_linux
```

**macOS:**

```bash
clang++ -std=c++17 front_end/*.cpp -o frontend_phase4_linux
```

