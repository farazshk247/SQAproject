## Declaration

Claude was used during Phase 1 of the project to help clarify some of the project requirements, brainstorm ideas for test cases, and organize our approach to testing.

The team reviewed the suggestions provided by Claude and made the final decisions regarding the project. Claude was mainly used as a support and clarification tool.

## AI Tool Used

**Tool:** Anthropic Claude  
**Approximate Date:** September 2026  

## Prompt History

### Prompt 1 – Project Requirements

**Prompt:**

> Can you explain the Phase 1 Front End requirements in simpler terms and tell us what we are expected to complete?

**How it was used:**

Claude helped clarify the project requirements and what was expected for the Phase 1 submission.

### Prompt 2 – Test Case Ideas

**Prompt:**

> What kinds of test cases should we consider for the different transactions in this project?

**How it was used:**

Claude was used to brainstorm possible valid, invalid, and boundary test cases. The team decided which test cases were relevant to the project requirements.

### Prompt 3 – Organizing Test Cases

**Prompt:**

> What is a good way to organize our test cases, input files, and expected output files?

**How it was used:**

Claude provided ideas for keeping the test cases organized and making the test files easier to understand and review.

### Prompt 4 – Checking Test Coverage

**Prompt:**

> How can we make sure our test cases cover the important requirements and constraints from the project handout?

**How it was used:**

Claude suggested checking each requirement against the test cases to make sure the important functionality and constraints were covered.

### Prompt 5 – Invalid and Boundary Inputs

**Prompt:**

> What are some invalid inputs and boundary cases we should consider when creating our tests?

**How it was used:**

Claude helped brainstorm possible edge cases such as invalid values, duplicate information, missing information, and values outside the allowed limits.

### Prompt 6 – Test Documentation

**Prompt:**

> What information should we include when documenting each test case?

**How it was used:**

Claude suggested including the purpose of the test, the input, the expected result, and the requirement being tested.

### Prompt 7 – Final Review

**Prompt:**

> What should we double-check before submitting Phase 1?

**How it was used:**

Claude suggested checking that the required transactions were covered, the expected outputs were correct, the files were organized consistently, and the submission matched the project requirements.

## Summary of AI Usage

Claude was used for:

- clarifying project instructions and requirements;
- brainstorming test-case ideas;
- identifying possible invalid and boundary cases;
- suggesting ways to organize test files;
- helping with test documentation;
- reviewing the general testing approach.

The team was responsible for reviewing the official project requirements, deciding which suggestions were appropriate, creating the final test cases, and preparing the final submission.
